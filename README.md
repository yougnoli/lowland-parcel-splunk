# Lowland Parcel Co. — Splunk app

This repository is your project in **DataGoLive**: a Splunk app for the fictional
parcel delivery company Lowland Parcel Co.

- Work on the `dev` branch. Commit and push from the code editor in your lab.
- Release by opening a pull request from `dev` to `main` on GitHub.
- Only the `default/` folder ships to PROD. Anything left in `local/` is not deployed.
- Write your project documentation in the `docs/` folder (start with `docs/README.md`). Your
  Tech Lead reviews it in your pull request.

The repository started from the DataGoLive template. You can keep it after the
project as part of your portfolio.
